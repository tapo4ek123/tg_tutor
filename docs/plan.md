## Реализовано

- [x] Модели данных и спецификация учебного цикла.
- [x] DeepSeek V4.1 Flash через Responses API и строгие JSON Schema.
- [x] Telegram private chat, inline buttons, справка и ограничение доступа.
- [x] Сбор профиля, диагностика, план с подтверждением.
- [x] Урок, скрытая служебная рубрика, проверка, подсказки, вопросы.
- [x] Целевая повторная практика и история изменений.
- [x] Итоговая работа без помощи и прогресс.
- [x] Настоящий stdio MCP и SQLite с revision.
- [x] Напоминания, timezone, retry, snooze, отключение.
- [x] Offline unit/integration/end-to-end тесты и машинный отчёт Eval.
- [x] 20 случаев для live предметного Eval.
- [x] Docker, Compose, lock-файлы, README, HTML-презентация.
- [x] Понятные ошибки провайдера (включая 403), безопасная CLI-диагностика API.

- [x] Несколько навыков, выбор и список, изоляция данных и миграция прежней цели.
- [x] Общий лимит $3/сутки, usage, атомарные резервы и сохранённое продолжение с кнопкой.
- [x] Обновлённые схемы, отдельный слайд MCP; убраны слайды Eval и демо.

- [x] Постоянное меню, пошаговая настройка, кнопки продолжения и напоминаний.
- [x] Раздельные режимы вопроса и решения с восстановлением после рестарта.

- [x] Сохранён baseline предыдущей модели: 19/20 на 20 ответах Go; новые результаты не подменяют старые.

- [x] Код и настройки переведены на официальный DeepSeek API (`deepseek-flash`).
- [x] Eval подготовлен: dry-run, повторы, отдельные отчёты и контрольные хэши.
- [x] Live Eval DeepSeek 30.10.2026: 18/20, 1 ошибка JSON; стоимость $0.009932004, отчёт и README обновлены.

## Требует внешних данных / среды

- [ ] Заполнить TELEGRAM_BOT_TOKEN и DEEPSEEK_API_KEY в локальном `.env`.
- [ ] Уточнить рубрику частичных ответов, расширить набор и повторить live Eval.
- [ ] Проверить сборку образа при запущенном Docker daemon.
- [ ] Разместить на постоянном сервере, проверить напоминание из Telegram.
- [ ] Опубликовать репозиторий и добавить ссылки на репозиторий и бот.
- [ ] Согласование темы / обязательный воркшоп / защита по правилам курса.
